## 摘要
键值（KV）缓存是加速大语言模型推理和生成的高效技术。推理工作负载规模大且多样化，这使得有效缓存它们变得困难。现有的缓存管理策略采用最近最少使用策略来驱逐缓存块。然而，LRU会导致多个不相关的工作负载相互刷新对方的缓存。为解决这一问题，我们集成了自适应缓存，该缓存在近期和频繁出现的KV块之间动态分配缓存空间。评估表明，在合成文档问答工作负载上，与朴素的vLLM相比，该方法将KV缓存命中率最多提升10.8%，将首次令牌生成时间最多降低12.6%；在真实对话工作负载上，这两个指标分别提升2.1%和2.0%。该方法能很好地泛化到批处理推理，并在有效适应多样化工作负载的同时展现出清晰的可解释性。

## Abstract
Key-value (KV) caching is a powerful technique for accelerating large language model inference and generation. Inference workloads are large and diverse, which makes them difficult to cache effectively. Existing cache management strategies adopt the least-recently-used policy for evicting cache blocks. However, LRU leads to multiple unrelated workloads flushing each other's caches. To address this, we integrate adaptive caching that dynamically allocates cache space between recently and frequently occurring KV blocks. Evaluations show that it improves the KV cache hit rate by up to 10.8% and reduces time to first token by up to 12.6% over naive vLLM on synthetic document question answering workloads, and 2.1% and 2.0% respectively on real-world conversation workloads. The method generalizes well to batch inference and demonstrates clear interpretability while effectively accommodating diverse workloads.

# 论文总结：面向大语言模型服务的近期/频率自适应KV缓存

## 1. 核心问题与整体含义（研究动机和背景）

大语言模型推理中，KV缓存是减少冗余计算的关键技术。然而，实际服务场景中工作负载多样且动态变化（如文档问答中的“热点”文档、多轮对话中的活跃用户），现有主流服务框架（如vLLM）采用简单的最近最少使用（LRU）驱逐策略，导致不同不相关的工作负载相互冲刷对方的缓存，缓存命中率低下。论文的核心问题是：**如何设计一种能够自适应地捕捉“近期性”和“频繁性”两种访问模式、并动态调整缓存空间分配的KV缓存管理策略，以提升LLM服务的缓存命中率和降低首令牌生成时间（TTFT）**。这项工作具有实际意义——提升缓存效率可直接降低推理延迟和计算成本，且方法无需人工调参，通用性强。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 核心思想
将自适应替换缓存（Adaptive Replacement Cache, ARC）引入LLM服务框架（vLLM），在GPU内存中实现**混合近期-频率**的驱逐策略。ARC通过两个关键机制实现自适应：

- **近期-频率双队列**：缓存逻辑上分为两个队列：
  - **低频率队列（L1 = T1 + B1）**：缓存仅被访问过一次的KV块，T1为物理缓存，B1为幽灵缓存（仅记录元数据）。
  - **高频率队列（L2 = T2 + B2）**：缓存被访问多次的KV块，T2为物理缓存，B2为幽灵缓存。
  - 当某个KV块在T1中被命中时，它被提升至T2的MRU端；当在T2中被命中时，它被移动到T2的MRU端（即保持在高频区）。

- **自适应缓存分区与幽灵缓存**：
  - ARC维护一个自适应参数 `p`（0 ≤ p ≤ 总缓存大小），用于控制T1和T2的物理大小比例（T1 = p，T2 = total - p）。
  - 幽灵缓存B1和B2存储已驱逐块的无数据，但不存实际KV值。当请求在B1中被命中（即该块刚被从T1驱逐）时，说明需要更多空间给T1，`p` 增大；当请求在B2中被命中时，`p` 减小。
  - 这种“幽灵命中”反馈机制使ARC能快速适应工作负载变化：当出现大量新请求冲刷T1时，T2内容得以保留；当近期重用增多时，T1自动扩大；当热点块出现时，T2自动扩大。

### 关键技术细节
- 以固定大小的KV块（如16个token）为粒度进行驱逐，与vLLM的分页注意力机制对齐。
- ARC无需任何参数，完全自调节；计算开销低，因为仅需维护少量元数据。

### 算法流程（文字说明）
1. 收到一个对KV块的请求。
2. 若块在T1或T2中 → 缓存命中：若在T1中则提升至T2的MRU端；若在T2中则移至T2的MRU端。
3. 若块在B1或B2中 → 缓存缺失但幽灵命中：需重新计算该块，并根据幽灵命中位置调整参数 `p`（B1命中→增大p，B2命中→减小p），然后将该块插入T2的MRU端，并从T1的LRU端驱逐一个块（放入相应幽灵队列）。
4. 若块不在任何缓存中 → 全缺失：从T1的LRU端驱逐一个块（移入B1），并将新块插入T1的MRU端（若T1已满则先驱逐一个块给T2腾空间）。
5. 强制保证T1和T2的物理大小之和等于总缓存容量。

## 6. 主要结论与发现

1. **文档QA场景**：
   - ARC比LRU提升命中率1.2%~10.8%（QuALITY）、2.5%~7.8%（WikiQA）；TTFT降低2.0%~12.6%（QuALITY）、3.6%~7.9%（WikiQA）。
   - 随着缓存容量增大，改进幅度减小（大缓存下驱逐决策影响小）。

2. **多轮对话场景**（真实追踪）：
   - ARC提升命中率1.1%~2.1%，TTFT降低1.0%~2.0%。
   - 自适应分区在大缓存（200k~300k）时贡献显著，而静态双队列（DBL）在大缓存下反而性能下降。

3. **批推理**：ARC优势在不同批大小（1/2/4/8）下保持稳定，命中率基本不变，TTFT绝对降低约5%~7%。

4. **自适应分区分析**：T1比例随时间动态变化，与工作负载波动一致。对话数据集中，大缓存下T1比例中位数更高（说明近期性更重要），而文档QA数据中T1比例在中段频繁振荡，反映了窗口化Zipf采样的影响。静态50/50分区（DBL）无法匹配这种动态性。

## 7. 优点

- **方法创新**：首次将自适应替换缓存（ARC）引入LLM服务场景，解决了LRU在多工作负载混合场景下的缺陷；ARC已在实际操作系统缓存中验证效果好，迁移到KV缓存是合理且有洞见的。
- **实用性**：无需调参、计算开销低、直接基于现有vLLM的KV块粒度实现，易于集成。

- **可解释性**：通过追踪T1比例随时间变化，直观展示了自适应行为如何适配工作负载漂移，有助于理解缓存行为。
