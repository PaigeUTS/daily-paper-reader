## 摘要
模拟内存计算（AIMC）加速器直接在内存阵列中执行矩阵-向量乘法，减少了数据移动并提高了DNN推理效率。其有限的有效精度促使了将模拟计算瓦片与数字处理单元相结合的异构架构。本文根据映射粒度、优化策略和模型支持，对现有在这些资源间划分DNN工作负载的方法进行了分类，并将其提炼为一个统一的四阶段工作流。为了在现有方法尚未涉及的模型类别上演示该工作流，我们将其前两个阶段应用于GPT-2，首次生成了仅解码器Transformer的AIMC特定精度敏感性剖面。敏感性由49个投影中的4个主导，其中第一个解码器块的注意力输出主导了一个数量级。这表明，投影级映射以及对早期块和面向输出投影的选择性数字执行，对于在AIMC硬件上可靠部署解码器Transformer至关重要。

## Abstract
Analog In-Memory Computing (AIMC) accelerators execute matrix-vector multiplications directly within memory arrays, reducing data movement and improving DNN inference efficiency. Their limited effective precision motivates heterogeneous architectures that combine analog compute tiles with digital processing units. This letter classifies existing methods for partitioning DNN workloads across these resources by mapping granularity, optimization strategy, and model support, and distills them into a unified four-stage workflow. To demonstrate the workflow on a model class not yet addressed by existing methods, we apply its first two stages to GPT-2, producing the first AIMC-specific precision sensitivity profile for a decoder-only transformer. Sensitivity is dominated by 4 of 49 projections, with the first decoder block's attention output dominating by an order of magnitude. This suggests that projection-level mapping and selective digital execution of early-block and output-facing projections are important for reliable decoder-transformer deployment on AIMC hardware.

### 核心思想

### 四阶段工作流（图2）
1. **Stage 1 – 硬件表征（HW Characterization）**  
   - 对目标加速器进行建模：瓦片数量/配置、数字CU能力（INT8/FP16/FP32）、瓦片I/O精度、存储层次、互连拓扑、候选分块策略（包括阵列利用率、权重复用、算术强度、内存流量等）。若使用易失性存储或非易失性存储（如PCM），需考虑刷新/漂移带来的时延和能耗开销。可借助CiMLoop等工具建立代理模型（如模拟MAC比例、数字权重大小）。

2. **Stage 2 – 精度敏感性分析（Precision Sensitivity Analysis）**  
   - 确定哪些DNN组件必须用数字执行、哪些可容忍模拟执行。技术包括扰动式剖面（O(L)前向传播）、Hessian特征分析、激活显著性等。核心发现：早期层和输出层通常对精度更敏感，因扰动会传播乃至直接影响最终logits。

3. **Stage 3 – 架构感知映射（Architecture-Aware Mapping）**  
   - 基于前两阶段的结果，应用优化策略（启发式、分析式或基于学习的方法，如超网络）将操作调度到异构资源。支持DNN架构调整（如调整层维度以提高瓦片利用率）。输出为精度-能耗/延迟的Pareto前沿。

4. **Stage 4 – 系统级评估（System-Level Evaluation）**  
   - 使用架构模拟器（DNN+NeuroSim、ALPINE、3DCiM）或物理硬件验证选定的映射方案。推荐报告任务精度（含误差棒）、模拟MAC比例、端到端延迟、每推理能耗以及映射搜索的计算成本。

## 6. 论文的主要结论与发现

1. **敏感性高度集中**：GPT-2-small的49个投影中，仅4个主导了大部分敏感性：  
   - **Block 0的注意力输出投影（c_proj）**：Δ=33.1，比其余高一个数量级。  
   - Block 1–2的FFN up投影（Δ≈14.0、11.8）、Block 0的FFN down投影（Δ=12.8）为第二梯队。  
   - 其余40个投影Δ<3，表明大部分层对模拟噪声相当鲁棒。
2. **内部投影而非首尾层最敏感**：与CNN中“首尾层最敏感”的常见模式不同，最敏感的投影是内部注意力输出（block 0），同时最后一个解码器块（block 11）的注意力输出和语言模型头也较敏感（Δ≈6~7）。
3. **注意力输出投影敏感性随块深度急剧变化**：中间块（2-10）的注意力输出投影非常鲁棒（Δ<0.22），而Q/K/V投影始终保持中等敏感度（Δ≈1-3）。这证明**块级粒度不足**，必须采用**投影级粒度**。
4. **对映射的启示**：  
   - 约82%的投影（40/49）可映射到模拟瓦片（Δ<3的保守阈值）。  
   - 优先将早期块和输出投影保留为数字执行。  
   - 敏感性剖面可作为Stage 3方法的输入（如初始化超网络路径权重、确定重训练顺序）。
