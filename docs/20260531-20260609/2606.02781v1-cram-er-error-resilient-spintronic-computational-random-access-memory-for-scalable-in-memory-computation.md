## 摘要
深度神经网络在多个领域取得了最先进的性能。然而，传统的冯·诺依曼计算范式面临严重的内存瓶颈。新兴的近内存和内存内计算方法缓解了这一问题，但带来了显著的外围开销。基于MRAM的计算随机存取存储器（CRAM）能够在不产生外围开销的情况下实现原位逻辑，提供了一种高密度、高能效的解决方案。然而，概率性的MRAM开关引入的门级误差限制了CRAM在加速深度神经网络时的可扩展性和可靠性。此外，大量的顺序MRAM写入严重制约了CRAM的吞吐量。为应对这些挑战，我们提出了一种抗错CRAM（CRAM-ER）架构，用于可扩展的内存内矩阵向量乘法。我们的错误感知硬件-软件协同设计框架采用混合自旋-CRAM + CMOS加法器树架构来减轻器件级误差的影响，展示了具有高面积和能效的矩阵向量乘法功能。我们进一步开发了错误感知模型微调和细粒度纠错，以增强抗错能力。在深度神经网络基准测试中对CMOS+自旋混合架构的评估显示，在将CRAM延迟降低多达两个数量级的同时，实现了近乎无损的精度，在能效和能量延迟积方面均优于CPU/GPU+高带宽DRAM。

## Abstract
Deep neural networks (DNNs) have achieved state-of-the-art performance across diverse domains. However, typical Von Neumann compute paradigms face severe memory bottlenecks. Emerging near-memory and compute-in-memory approaches alleviate this but incur significant peripheral overhead. Computational Random Access Memory (CRAM) based on MRAM enables in-situ logic without peripheral overhead, offering a dense, energy-efficient solution. However, probabilistic MRAM switching induces gate-level errors that limit the scalability and reliability of CRAM for accelerating DNN. Moreover, the large number of sequential MRAM writes severely constrains CRAM throughput. To address these challenges, we propose an error-resilient CRAM (CRAM-ER) architecture for scalable in-memory matrix-vector multiplications (MVMs). Our error-aware hardware-software co-design framework leverages a hybrid spintronic-CRAM + CMOS adder-tree architecture to mitigate the impact of device-level errors, demonstrating MVM functionality with high area and energy efficiency. We further develop an error-aware model fine-tuning and fine-grained error correction for enhanced error resilience. Evaluations of the CMOS+spintronic hybrid architecture on DNN benchmarks show near-lossless accuracy while reducing CRAM latency by up to 2 orders of magnitude, outperforming CPU/GPU+high-bandwidth DRAM in both energy efficiency and energy-delay product.

*   **核心问题**：传统的冯·诺依曼计算架构在执行数据密集型深度神经网络（DNN）时，面临严重的“内存墙”瓶颈，即数据在内存与计算单元间的频繁移动消耗大量时间和能量。虽然新兴的“近内存计算”和“内存计算”方法能缓解此问题，但通常引入显著的外围电路开销（如模数转换器）。
*   **研究背景**：
    1.  **CRAM的优势**：基于MRAM的计算随机存取存储器（CRAM）通过修改标准1T1M存储单元为2T1M结构，实现了直接在存储阵列内执行逻辑运算，无需额外外围电路，具有高密度、高能效和非易失性的优势。
    2.  **CRAM的挑战**：
        *   **可靠性问题**：MRAM的磁性状态切换（写操作）具有概率性（遵循热激活模型），导致门级计算存在固有错误率（δ）。随着计算复杂度（如多比特MAC操作）增加，错误会累积，严重损害DNN的推理精度。
        *   **吞吐量瓶颈**：执行复杂的DNN运算（如矩阵向量乘法MVM）需要大量的顺序MRAM写操作，严重限制了CRAM的吞吐量和系统效率。
*   **整体含义**：本文旨在解决现有的纯CRAM架构无法可靠、高效地加速大规模、多比特DNN这一关键问题。作者提出了CRAM-ER，一个首次将CRAM应用于加速多比特DNN（包括卷积神经网络CNN和视觉Transformer ViT）的可行方案。

### 论文提出的方法论：核心思想与关键技术细节

1.  **核心思想**：采用硬件-软件协同设计方法，在硬件层面引入混合架构以缓解错误和延迟，在软件层面采用误差感知训练进一步提升鲁棒性。

2.  **关键技术细节（硬件层面）**：
    *   **混合架构（CRAM + CMOS加法器树）**：
        *   将MAC（乘累加）运算进行分解。
        *   所有**乘法运算**和**大部分累积运算**（约75%）仍在CRAM阵列内原位执行，以利用其高密度和低功耗优势。
        *   **小部分（例如25%）高速关键累积运算**（如最终的求和）被转移到外部**CMOS数字加法器树**中完成。由于CMOS加法器是无错误的，可以消除这部分累积过程中的误差累积，同时显著减少了CRAM中昂贵的MRAM写操作次数，大幅提升吞吐量。
    *   **选择性位纠错（Selective Bit Error Correction）**：
        *   引入一个低开销的“MAJ3”纠错电路，对同一个运算结果生成三次，然后取它们的多数值作为最终输出。
        *   基于“最高有效进位位对精度最为关键”的洞察，纠错策略仅在**加法器树的最高有效进位位**上应用，以在面积、能耗和纠错效果之间取得最佳平衡。

3.  **关键技术细节（软件层面）**：
    *   **高保真误差建模**：
        *   首先在PyTorch中实现概率性的NAND门模型（基于MTJ器件的热激活模型参数）。
        *   然后基于此构建全NAND加法器、脉动阵列乘法器等底层模块。
        *   模拟固定大小的矩阵乘法在CRAM中的运算，统计出输出比特位的错误率。
    *   **误差感知模型微调（Error-aware Fine-tuning）**：
        *   步骤1：训练一个量化（Q-bit）的基线DNN模型。
        *   步骤2：将权重和输入表示为Q位无符号整数。
        *   步骤3：使用模拟出的CRAM位级错误率对模型进行**带噪微调**，使模型权重学习适应这种硬件噪声，从而在推理时恢复精度。
